Від запису вебінару до обробки домашнього відео — часто потрібно щось зробити з відео. Думаєте, що потрібна дорога профпрограма? Ні. На Windows є чудові безкоштовні інструменти для кожного кроку.

---

## Крок 1: Запис відео з екрана

### Вбудований інструмент Windows — найпростіше рішення

Windows 10/11 має вбудований запис екрана — **Game Bar**. Натисніть **Win + G**:

- **Win + Alt + R** — почати запис
- **Win + Alt + R** — зупинити запис
- Відео зберігається в папці `Videos\Captures`

Цього достатньо для більшості задач: вебінари, навчальні відео, демонстрації.

> **Нюанс:** Game Bar записує звук з системи. Якщо потрібен мікрофон — використовуйте інші інструменти.

---

## Крок 2: Редагування відео

Якщо записали щось, але треба видалити початок/кінець, додати титри, перетворити динамічні фрагменти — використовуйте **[DaVinciResolve](/program/davinci-resolve)**.

Безкоштовна версія вміє:

- ✂️ Нарізати, склеювати клипи
- 📝 Додавати титри та текст
- 🎨 Базова колірна корекція
- 🎵 Робота зі звуком (гучність, вирівнювання)
- 🎬 Переходи та ефекти (базові)
- 💾 Експорт у популярні формати

**Алгоритм роботи:**

1. Завантажіть записане відео у DaVinciResolve
2. На вкладці **Edit** (монтаж) розташуйте клипи, видаліть непотрібне
3. На вкладці **Color** (колір) покращіть освітлення/контраст, якщо потрібно
4. На вкладці **Fusion** (ефекти) додайте титри або переходи
5. На вкладці **Deliver** (вихід) експортуйте готовий файл

Перша робота може зайняти час — є крива навчання. Але результат — професійний.

---

## Крок 3: Конвертирування формату

Записали в одному форматі, а потрібно в іншому? Чи потрібно файл для різних пристроїв?

**[ShutterEncoder](/program/shutter-encoder)** — простий і швидкий конвертор:

- Перетворює між форматами (MP4, MKV, AVI, MOV тощо)
- Підтримує кодеки: H.264, H.265, VP9, AV1
- Параметри обробки прості навіть для новачків
- Батна обробка (обробити кілька файлів разом)

**Як користуватись:**

1. Перетягніть відео у вікно ShutterEncoder
2. Оберіть формат видео та аудіо
3. Натисніть **Start** — чекаєте
4. Готовий файл з'явиться поруч з оригіналом

## Крок 4: Стиснення і оптимізація

Якщо відео великий і потрібно скоротити розмір — знову допоможе ShutterEncoder чи DaVinciResolve, але з налаштуванням **бітрейту**:

**Типові значення для різних завдань:**

| Завдання | Кодек | Бітрейт | Результат |
| --- | --- | --- | --- |
| Соціальні мережі (Telegram, YouTube) | H.264 | 2-5 Мбіт/с | Хороша якість, малий файл |
| Архів / хранилище | H.265 | 1-3 Мбіт/с | Дуже хороша якість, вдвічі менше ніж H.264 |
| Локальна мережа / ПК | H.264 / H.265 | 8-15 Мбіт/с | Висока якість |
| Кінематографічна якість ( 4K) | H.265 / AV1 | 15-50 Мбіт/с | Максимум |

**Поради:**

- Знайдіть баланс між якістю та розміром — експериментуйте
- H.265 економить місце, але старі пристрої його не підтримують
- Завжди прослухайте фрагмент перед експортом всього файлу

## Крок 5: Робота зі звуком

Якщо запис мав гарні шуми або сирену на фоні — відредагуйте звук окремо.

**[Audacity](/program/audacity)** — редактор звуку:

- Витяг звуку з відео (File → Import → Audio)
- Видалення шумів та тишини
- Нормалізація (вирівнювання гучності)
- Накладання музики/голосу

**Алгоритм:**

1. Завантажте звукову доріжку з відео у Audacity
2. Відзвучите шуми (Effect → Noise Reduction)
3. Нормалізуйте гучність (Effect → Normalize → Громкість -3 db)
4. Експортуйте як MP3 або WAV
5. Повторно імпортуйте звук у DaVinciResolve, синхронізуйте з відео

## Швидкий гайд для новачка

**Сценарій 1: Записав вебінар, потрібно видалити початок/кінець**
→ Game Bar (запис) → DaVinciResolve (монтаж) → готово

**Сценарій 2: Відео занадто велике для Telegram**
→ ShutterEncoder → H.265, 3-5 Мбіт/с → відправити

**Сценарій 3: Потрібно відео для YouTube з титрами**
→ Game Bar (запис) → DaVinciResolve (монтаж + титри) → експорт H.264 / YouTube preset

**Сценарій 4: На фоні гарні шуми**
→ Game Bar (запис) → Audacity (очищення звуку) → експорт звуку → DaVinciResolve (синхронізація) → готово
